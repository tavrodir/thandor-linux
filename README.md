# thandor-linux
Linux-Port für Thandor - Die Invasion

Das ist ein Fan-Port, um das Spiel "Thandor - Die Invasion" aus dem Jahr 2000 auf modernen Rechnern nativ unter Linux zu spielen. Du benötigst weder Wine noch Proton oder dergleichen.

** HINWEIS für mögliche Rechteinhaber des Spiels: Das Spiel scheint ja "Abondonware" zu sein. Sollte sich doch noch ein aktueller Rechteinhaber finden und nicht mit dieser Veröffentlichung einverstanden sein, dann melden Sie sich bitte bei mir und ich werde das Spiel offline nehmen. **

Das Spiel hat es nicht verdient, in Vergessenheit zu geraten. Daher habe ich mit Hilfe von Codex einen Port für Linux erstellt. Benötigt werden:
- x86-System
- Grafiktreiber mit Vulkan-Unterstützung
- XWayland zum Spielen unter Wayland
- Aktuelle Systembibliotheken, zum Testzeitpunkt waren das: glibc 2.38, glibcxx_3.4.32, libatomic.so.1, libgcc_s.so.1

Multiplayer ist momentan nicht implementiert.

Mit Strg+F lässt sich eine fps-Anzeige einblenden. Patch 1.05 ist bereits enthalten, d.h. mit G lässt sich das Spiel beschleunigen, mit Alt+G wieder verlangsamen.

Viel Spaß beim Spielen und Schwelgen in Erinnerungen! :)
